## 🏛️ The Core Pedagogical Architecture (The 3-Layer Standard)

Every lesson across Key Stage 2, Key Stage 3, and GCSE must enforce:
1. **Layer 1: Narrative Exposition Blocks (5 Chronological Acts):**
   - Narrative divided into structured chronological stages (Blocks 1–5).
2. **Layer 2: Visual Support Plates (Alternating Rhythm):**
   - 2 to 3 authentic visual plates flanking the narrative text (`.narrative-visual-row`).
3. **Layer 3: Rotated Disciplinary Sources (Sources A–E):**
   - Exactly 5 primary archival sources per lesson in collapsible drawers positioned beneath narrative containers.
4. **The Strict 1-to-1 Chronological Alignment Rule:**
   - **Block 1** ➔ **Source A** (Must directly evidence the historical mechanism of Block 1).
   - **Block 2** ➔ **Source B** (Must directly evidence the historical mechanism of Block 2).
   - **Block 3** ➔ **Source C** (Must directly evidence the historical mechanism of Block 3).
   - **Block 4** ➔ **Source D** (Must directly evidence the historical mechanism of Block 4).
   - **Block 5** ➔ **Source E** (Must directly evidence the historical mechanism of Block 5).
5. **Zero Intra-Lesson Duplication Gate:**
   - No image file or specific artifact/text may be duplicated within the same lesson (neither between Layer 2 and Layer 3, nor across Sources A–E).
   - If an artifact appears as Source A, it must NOT appear again as Source E.
   - If a source does not fit a block, it is **never** doubled up into another block; it is **reshuffled** to its true chronological block or **swapped out** for an authentic primary source addressing the missing topic.

## 🛠️ The 3-Step Remediation Protocol

Whenever a unit is audited:
1. **Step 1: Reshuffle (Sequence Correction):**
   - If authentic sources exist in the lesson but are out of order, move them to their corresponding narrative block (e.g. moving Pepys' 1660 cellar diary from Block 2 to Block 4).
2. **Step 2: Swap-Out (De-Duplication & Void Elimination):**
   - If a source is duplicated (e.g. Harington's toilet appearing twice in Lesson 3) or irrelevant, swap it out for an authentic primary source specifically covering the orphaned block (e.g. John Stow's 1598 *Survey of London* for Tudor street filth; New River charter for 1613 water supply).
3. **Step 3: Verification & Re-compilation:**
   - Register any new source in `scripts/master_rights_database.json`.
   - Run `node scripts/audit_intra_lesson_duplicates.cjs`.
   - Run `node scripts/verify_gallery_assets.cjs`.
   - Run `node scripts/sync_unit.cjs <unit_id>`.
